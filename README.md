This is my personal portfolio website, and you can see it live at https://clanky.me/porfolio/. I built it from scratch with plain HTML, CSS and a little JavaScript, with no frameworks. It is one scrolling page with Home, About, Services, Portfolio and Contact sections, in a dark theme with a pink accent colour. I used Flexbox, Grid and media queries so it works on phones, where the menu turns into a slide-in side menu. The contact form sends messages to a Google Sheet using Google Apps Script, so I did not need to write my own backend. The Portfolio section shows the website I made for my school, Gorkha Secondary School in Tulsipur, Nepal.
